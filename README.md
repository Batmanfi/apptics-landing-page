# Apptics landing page

Responsive static implementation of the finalized Apptics landing page design.

## Run locally

Open `index.html` through any local static file server.

## Validate and build

```sh
npm run check
npm run build
```

The production-ready static files are written to `dist/`.

## Icons

The hero uses the official [Phosphor CheckCircle Fill SVG](https://github.com/phosphor-icons/core/blob/main/assets/fill/check-circle-fill.svg), with its fill set to the page's text color. It is served locally without an icon-font or JavaScript dependency. The MIT license is included in `assets/PHOSPHOR-LICENSE.txt`.
